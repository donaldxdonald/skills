# Branding

## Overview

Branding is the deliberate alignment of strategy and expression. Start by defining what the brand should mean to a specific audience, then design how that meaning shows up across messaging, visuals, product, sales, support, and community touchpoints.

## Core Rule

Never treat a logo, palette, tagline, or style board as the brand. They are expressions of the brand. If strategy is unclear, pause visual production long enough to define audience, promise, differentiation, personality, proof, and the touchpoints where consistency matters.

## Quick Workflow

1. **Diagnose the job** - Identify whether the user needs strategy, messaging, identity, rebrand, audit, guidelines, launch assets, or feedback.
2. **Lock the foundation** - Write the audience, pain, outcome, category, point of difference, promise, reasons to believe, personality, and "not this" constraints.
3. **Map the touchpoints** - List where the brand must show up: website, sales calls, PR, social, product UI, onboarding, emails, packaging, decks, invoices, support, community replies.
4. **Create the expression system** - Derive name, tagline, voice, logo direction, type, color, imagery, motion, layout, and templates from the foundation.
5. **Test for memory and consistency** - Ask whether a customer can repeat what the brand does, why it matters, and what makes it different. Check whether every channel tells the same story.
6. **Document reusable assets** - Deliver concise guidelines, approved messages, examples in context, and rules for what to avoid.

## Discovery Questions

Use these before creating identity work:

| Area        | Questions                                                                                                       |
| ----------- | --------------------------------------------------------------------------------------------------------------- |
| Audience    | Who is this for? What do they already believe, buy, compare, fear, and want?                                    |
| Category    | What category will customers place this in? What alternatives are they using now?                               |
| Difference  | What should only this brand be able to credibly claim? What should it exclude?                                  |
| Promise     | What outcome does the brand make easier, safer, faster, more prestigious, or more meaningful?                   |
| Proof       | What evidence, product behavior, founder story, data, customer proof, or community signal supports the promise? |
| Personality | If this brand were a person, how would it speak and behave? What would it never sound like?                     |
| Touchpoints | Where will customers encounter the brand before, during, and after purchase?                                    |
| Constraints | What must stay? What must change? What legal, market, accessibility, cultural, or production constraints apply? |

## Strategy Before Expression

Use this distinction when users conflate branding with design:

| Layer            | Defines                                                                         | Outputs                                                                                     |
| ---------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Brand strategy   | Meaning, market position, audience, promise, differentiation, values, messaging | Positioning statement, audience insight, value proposition, messaging pillars, proof points |
| Brand expression | How the strategy is experienced                                                 | Name, logo, color, typography, voice, layout, imagery, packaging, website, decks, templates |
| Brand operations | How consistency is maintained                                                   | Guidelines, asset library, approvals, examples, monitoring, governance                      |

## Practical Outputs

For a new brand, produce:

- Positioning statement: `For [audience], [brand] is the [category] that [promise], unlike [alternatives], because [proof].`
- Messaging pillars: 2-4 repeatable ideas with proof points and sample copy.
- Voice rules: 3-5 personality traits plus "sounds like / does not sound like" examples.
- Visual territories: 2-3 directions shown in real touchpoints before logo refinement.
- Identity system: logo, type, color, layout, imagery, iconography, motion, and usage rules.
- Brand kit: source files, exports, templates, taglines, short descriptions, launch copy, and example applications.

For a rebrand or audit, produce:

- Current perception versus desired perception.
- Fragmentation map across sales, website, PR, product, community, and support.
- Keep/change/remove recommendations.
- Migration risks: recognition loss, SEO, customer confusion, internal adoption, asset debt.
- Rollout plan with internal enablement before public launch.

## Community-Informed Practices

Recent r/branding discussion reinforced these patterns:

- Fragmented messaging is a strategic problem, not a cosmetics problem.
- Self-branding needs distance: treat it like a client project and get outside eyes.
- Useful critique requires context: audience, competitors, desired perception, constraints, and examples.
- Brand monitoring matters: track how people naturally mention the brand, not just owned-channel metrics.
- Good branding systems need tools and assets for repeated use, not only a final presentation.

## Common Mistakes

| Mistake                                       | Fix                                                                                                                                 |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Starting with logo concepts                   | First define audience, promise, difference, proof, personality, and touchpoints.                                                    |
| Targeting "everyone"                          | Name the primary audience and who the brand deliberately excludes.                                                                  |
| Writing a clever tagline before positioning   | Write the positioning statement first; tagline is a compressed expression of it.                                                    |
| Making a moodboard with no strategic criteria | Label each direction by the perception it should create and the audience it serves.                                                 |
| Delivering files without governance           | Include usage rules, examples, naming/export conventions, and owners.                                                               |
| Ignoring real conversations                   | Monitor Reddit, reviews, support tickets, sales calls, search queries, and social mentions for the language customers actually use. |

## Response Pattern

When answering branding requests:

1. State the strategic diagnosis in one paragraph.
2. Give the next 3-7 actions in order.
3. Include concrete questions or templates the user can use immediately.
4. If asked for visuals, tie each visual choice back to the desired perception.
5. If information is missing, make reasonable assumptions and label them, or ask only the highest-leverage question.
